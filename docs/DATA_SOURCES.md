# Data Source Register

**Policy:** No automated fetch or scrape is authorized by this register unless the source's terms and robots.txt have been reviewed for the exact host, path, user agent, purpose, and access method. A 200 response for robots.txt does not grant permission under terms. Never bypass a 403, login, CAPTCHA, paywall, or other access control. Prefer official APIs, feeds, sitemaps, and manufacturer-published structured data only when terms permit the intended reuse. Last checked: 2026-10-21.

The scraper fleet now enforces this in code: `veridian_scraper/scrapers/base.py` retrieves and caches each host's `robots.txt`, evaluates it against the honest `VeridianBot` user agent before **every** request, and refuses the request rather than fetching it when the path is disallowed. A source whose policy cannot be retrieved is refused as well — it is never treated as "no restrictions".

## Collection Rules

- Before enabling a source, add a dated source review with the applicable ToS/robots URLs, relevant sections/directives, allowed access method, crawl delay/rate limit, retention/reuse limits, and reviewer.
- Use an identifiable Veridian user agent with contact details; do not impersonate a browser or evade access controls.
- Respect `Disallow` and declared crawl delays; if robots policy is unavailable or ambiguous, stop and mark the source unavailable pending written clarification.
- Evaluate the robots policy identically on every Python version: the decision follows RFC 9309, because the standard library's parser changed its semantics between 3.12 and 3.14.
- Store only data reasonably necessary to the product, including raw observation hash and source URL. Respect license, attribution, retention, and redistribution terms.
- No retailer scraping is enabled. Retailer prices require a source-specific legal/terms gate and an official API/feed or documented permission.
- Never present the local CSV or its derived rows as verified or live. Any synthetic fixture must be unmistakably labeled and excluded from public catalog and price claims.
- A source that is unreachable, blocked or unvalidated is recorded as such. It is never reported as working because a process exited with status zero.
